# ORE Homebrew tap

```sh
brew install --cask openresearchh/tap/ore
```

`Casks/ore.rb` is stamped from
[`packaging/homebrew/ore.rb`](https://github.com/OpenResearchh/ore/blob/master/packaging/homebrew/ore.rb)
by `Apps/OreMac/Scripts/certify-release.sh` on every release, with that
release's version and checksum. Edit the template in the ORE repository, not
the copy here.

Until the first release is published through the script, this tap has no cask.
